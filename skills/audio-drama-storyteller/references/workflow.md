# Workflow

## 1. Adapt prose into listening format

Turn flat text into beats.

Preferred structure:

```text
[SCENE 1]
NARRATOR: ...
SFX: rain under
CHARACTER: ...
PAUSE: short
NARRATOR: ...
```

Guidelines:
- one idea per spoken chunk
- short paragraphs
- use pauses intentionally
- move visual-only description into emotional or sensory language

## 2. Cue sheet mindset

Good cue categories:
- `ambience`
- `transition`
- `impact`
- `stinger`
- `closing`

Avoid:
- constant SFX on every line
- loud music under important speech
- comedic effects unless the tone really asks for it

## 3. Rendering ladder

If the user is exploring:
- render a 20-40 second proof first

If the style is approved:
- render the full piece

## 4. Final file layout

Suggested folders:

```text
output/audio-drama/
  script/
  clips/
  mix/
```
